## ⚡ Quick Install

### n8n Community Node (UI)
In n8n: **Settings** &rarr; **Community Nodes** &rarr; **Install**:
```text
n8n-nodes-devdeskapp
```

### Docker / CLI
```bash
npm install n8n-nodes-devdeskapp
```

---

## 🛠️ Run Docs Locally

```bash
npm install
npm run docs:dev     # http://localhost:5173
```
